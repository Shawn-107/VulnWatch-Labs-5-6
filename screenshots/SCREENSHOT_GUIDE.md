# Required screenshots for the lab submission

Capture **real screenshots from a running app** (do not fabricate screenshots). Place them in this folder.

| File to save | Action to show | Evidence |
|---|---|---|
| `01-read.png` | Open the Watchlist at initial load | Six records and summary metrics |
| `02-create.png` | Add `Kubernetes` v1.31.0, High, Production | Record appears; count increases to seven |
| `03-update.png` | Edit Kubernetes to Critical priority and v1.31.1 | Updated row visible |
| `04-delete.png` | Delete Kubernetes and confirm | Record absent; count returns to six |
| `05-search.png` | Search `PostgreSQL`, filter Critical | Only PostgreSQL appears |

To reset local records, use **Restore sample watchlist** in the Watchlist section. Screenshots should show the actual browser app after the action, not just source code.
